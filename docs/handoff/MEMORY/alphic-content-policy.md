**🔴 TAB HYGIENE (Itamar, 2026-06-22 — he opened Chrome and found DOZENS of tabs):** every spawned social/browser cycle was calling `tabs_create_mcp` (new tab) and not reliably closing it (close attempts time out on blocking dialogs), so tabs pile up. FIX, now mandatory for ALL Alphic/browser cycles: (a) REUSE the existing /AlphicIo tab — call `tabs_context_mcp` first, find an open x.com/AlphicIo tab and `navigate` it, instead of creating a new tab; only create a tab if none exists. (b) At the END of every cycle, CLOSE any tab the cycle opened (dismiss blocking beforeunload dialogs first). (c) Never leave draft/compose tabs open. Keep ONE persistent X tab, reuse it every cycle.

**🔴 MEDIA-UPLOAD NEEDS A FOREGROUNDED TAB (confirmed 2026-06-22):** even with a real-SIZED window, X's media upload spins forever and silently drops the image if the tab's `document.visibilityState === 'hidden'` (i.e. the tab/window isn't the actually-focused foreground tab). Real-sized ≠ foregrounded. So for a post to carry a visual, the X tab must be genuinely in the FOREGROUND (focused), and the cycle must POLL until the upload completes (the image's ALT button appears) before clicking Post — abort the attach and go text-only rather than post a caption referencing a missing chart. Likes, replies, follows, and text posts all work regardless of foreground state; only media upload needs it.
