# SMS Bridge — הודעות ה-SMS מטלפון האנדרואיד שלך, בכל מכשיר אחר שלך, בלחיצה

SMS Bridge מעביר את הודעות ה-SMS מטלפון (או טלפונים) אנדרואיד **שלך** אל **מכשיר אחר שלך**:
טלפון אנדרואיד נוסף, אייפון, טאבלט או דפדפן במחשב. הוא נועד לחיבור בין מכשירים של אותו אדם בלבד —
למשל טלפון העבודה והטלפון הפרטי, או טלפון שני שנשאר בבית — ולא לשיתוף הודעות עם אנשים אחרים.

לוחצים **"רענן"** במכשיר שבו אתה קורא ← כל טלפון אנדרואיד שלך שחיברת מתעורר לשנייה, שולח את ההודעות מהזמן האחרון ← הן מופיעות אצלך.
בשאר הזמן **האפליקציה באנדרואיד לא רצה בכלל**.

- **שני תפקידים.** המכשיר שבו אתה קורא הוא ה**בקר**: מגדירים בו פעם אחת Firebase, בדף אינטרנט שעובד בכל דפדפן
  (Chrome באנדרואיד, Safari באייפון, טאבלט או מחשב). כל טלפון אנדרואיד שלך שתחבר הוא **שולח**:
  מתקינים בו אפליקציה ופותחים קישור. **אין בו גישה ל-Firebase, אין חשבון, אין הגדרות.**
- **כמה טלפונים שלך למכשיר אחד.** מחברים 2, 3 או יותר מהטלפונים שלך (למשל "טלפון העבודה", "הטלפון השני שלי").
  ההודעות מוצגות יחד עם תווית לכל טלפון, או מסוננות לפי טלפון.
- **בלי Tailscale ובלי צריכת סוללה.** אין שירות רקע באנדרואיד; הוא מתעורר רק כשאתה מבקש.
- **מוצפן מקצה לקצה.** לכל טלפון מפתח AES משלו, שעובר רק בקישור החיבור. Firebase רואה רק טקסט מוצפן,
  והאנדרואידים לא מחזיקים שום מפתח ניהול.
- **קריאה בלבד ובהסכמה.** האפליקציה לא שולחת/מוחקת הודעות. בטלפון השולח יש מסך גילוי והסכמה, אייקון גלוי, הודעה קבועה
  "משתף SMS עם …", והתראה על כל משיכה. **התקן רק בטלפונים שלך.**

## איך זה עובד

```
  המכשיר השני שלך (בקר)             Google (Firebase, חינם)                  האנדרואיד שלך (שולח)
  ─────────────                       ───────────────────────                  ───────────────
  "רענן את כל הטלפונים"  ──דחיפה בעדיפות גבוהה לכל טלפון──────────────────▶  מתעורר לכמה שניות
                                                                              קורא SMS מהטווח שבחרת
                              ◀──מעלה מוצפן לקופסה שלו─────────────────────  וחוזר לישון
  מושך, מפענח ומציג  ◀───────  מסד נתונים (קופסה לכל טלפון)
```

- כל טלפון = "קופסה" (נתיב סודי במסד הנתונים) עם מפתח הצפנה משלה.
- הבקר (המכשיר שבו אתה קורא: אנדרואיד, אייפון, טאבלט או מחשב) מחזיק את מפתח ה-service account, שולח את הדחיפות וקורא את התשובות כמנהל.
- השולח (האנדרואיד) מחזיק רק את ההגדרות הציבוריות + הקופסה + המפתח שקיבל בקישור. הוא כותב את תשובתו
  ישירות למסד (כתיבה לא-מאומתת לנתיב סודי שהבקר הקצה מראש), בלי שום מפתח מנהל.

**בלי שרת משלנו.** Firebase הוא רק תיבת דואר מוצפנת, חינמי לשימוש הזה (תוכנית Spark), בלי כרטיס אשראי.

## התקנה

### א. פעם אחת, במכשיר שבו תקרא את ההודעות (הבקר) — כ-5 דקות

הבקר יכול להיות כל מכשיר שלך עם דפדפן: טלפון אנדרואיד נוסף (Chrome), אייפון (Safari), טאבלט או מחשב.

1. פרויקט Firebase חינמי: <https://console.firebase.google.com> ← **Create a project**.
2. רושמים אפליקציית אנדרואיד: **Add app ← Android**, שם החבילה **`com.itamar.smsbridge`** ← **Register app** ←
   מורידים **`google-services.json`**.
3. מפתח ניהול: ⚙️ **Project settings ← Service accounts ← Generate new private key** ← יורד קובץ JSON.
4. פותחים את **דף הבקר** במכשיר הזה (ראו "איפה הדף" למטה), בוחרים את **שני הקבצים** שירדו (יחד, או אחד אחרי השני),
   ולוחצים "התחל הגדרה". הדף יוצר ונועל את מסד הנתונים לבד. הכל נשמר רק במכשיר הזה שלך.

> אם אין Realtime Database בפרויקט, הדף יוצר אותו. אם תעדיף ליצור ידנית: **Build ← Realtime Database ← Create database**.

### ב. לכל טלפון אנדרואיד שלך שתרצה לחבר

1. בדף הבקר: **"+ חבר טלפון נוסף שלי"**, נותנים שם (למשל "טלפון העבודה" או "הטלפון השני שלי"). נוצר **קישור חיבור** —
   שולחים אותו לעצמך (מייל, הודעה) כדי לפתוח אותו בטלפון האנדרואיד שלך.
2. פותחים את הקישור בטלפון האנדרואיד. מסך החיבור כולל הכול בקישור אחד:
   כפתור **"1. הורד והתקן את האפליקציה"** (ה-APK מוגש מאותו אתר), ואז **"2. פתח באפליקציה"** ומתן הרשאת **SMS**.
   אין צורך לשלוח את ה-APK בנפרד. (אם אנדרואיד מזהיר שהקובץ "לא בטוח": פרטים נוספים ← התקן בכל זאת.)
3. שיעבוד תמיד: בטלפון השולח, **הגדרות ← סוללה ← אפליקציות שאף פעם לא נרדמות** ← להוסיף את SMS Bridge,
   ובפרטי האפליקציה לכבות "השהה פעילות אם לא בשימוש". זה לא עולה בסוללה (אין רקע), רק מונע הרדמה.

חוזרים על ב' לכל טלפון נוסף.

### השגת ה-APK

ה-APK **גנרי וללא סודות** (הוא מוגדר כולו מקישור החיבור). הדרך הרגילה: מורידים אותו בטלפון ישירות
מתוך מסך החיבור (כפתור "הורד והתקן"). הקובץ מוגש מאותו אתר, בנתיב `sms-bridge/web/SMS-Bridge.apk`.
אפשר גם להורידו מלשונית **Actions** ← הריצה האחרונה של **SMS Bridge APK** ← תחת **Artifacts** ← `sms-bridge-apk`,
או לבנות מקומית: `cd sms-bridge/android && ./gradlew assembleRelease`.

> **עדכון ה-APK שבאתר:** `web/SMS-Bridge.apk` הוא עותק מתוך התיקייה הזאת (מעוקף ב-`.gitignore` במכוון).
> אחרי שינוי בקוד האנדרואיד, החליפו אותו בפלט בנייה חדש (`app/build/outputs/apk/release/app-release.apk`) ו-commit.

### איפה הדף (הבקר)

דף הבקר הוא קובץ סטטי יחיד, `sms-bridge/web/index.html`, בלי סודות. אפשר לארח אותו בכל מקום עם HTTPS.
הדף עובד בכל דפדפן עדכני — Chrome באנדרואיד, Safari באייפון, וכל דפדפן בטאבלט או במחשב.
הכי פשוט: בהגדרות הריפו ב-GitHub **Settings ← Pages ← Deploy from a branch** ← הענף, תיקייה `/ (root)`,
ואז הדף ב-`https://itamarvanu-dot.github.io/tradevision-research/sms-bridge/web/`. קישורי החיבור שהדף מייצר
מצביעים חזרה לאותה כתובת, כך שגם מסך החיבור של השולח מוגש מאותו דף.

## שימוש יומיומי

פותחים את דף הבקר במכשיר שבו אתה קורא. נוח להוסיף אותו למסך הבית:
באנדרואיד (Chrome): תפריט ⋮ ← **הוספה למסך הבית**; באייפון (Safari): שיתוף ← **הוסף למסך הבית**; במחשב: סימנייה.

- **"רענן את כל הטלפונים"** מושך מכולם במקביל. אפשר גם לרענן טלפון בודד מכרטיס הטלפון.
- **טווח זמן** (15 דק׳ עד 3 ימים, או 50 אחרונות) ו**בחירת טלפון** (הכל / טלפון מסוים) בשורות הכפתורים.
- **חיפוש** בגוף ההודעה, בשם השולח ובשם הטלפון; סינון **"לא נקראו"**.
- **קודי אימות** מוצגים ככפתור העתקה. הודעות חדשות מודגשות בירוק.
- לכל טלפון מוצגים הדגם, מצב הסוללה ומתי עודכן לאחרונה. הודעות שנמשכו נשמרות בדפדפן של מכשיר הבקר.
- **החשבון נשמר בענן.** רשימת הטלפונים שחיברת נשמרת גם במסד הנתונים (באזור שרק המנהל ניגש אליו).
  אם הדפדפן נמחק, או שאתה פותח את הדף ממכשיר אחר — פשוט בחר שוב את שני הקבצים, וכל הטלפונים חוזרים.
  זה אותו חשבון תמיד; שני הקבצים הם הזהות שלך.

## אבטחה ופרטיות

- **הצפנה מקצה לקצה לכל טלפון.** מפתח AES-256 נפרד לכל טלפון, שעובר רק בקישור החיבור (בחלק שאחרי ה-`#`,
  שהדפדפן לא שולח לשרת). ב-Firebase נשמר רק טקסט מוצפן.
- **מסד נתונים נעול.** קריאה וכתיבה כלליות אסורות. אנדרואיד יכול לכתוב **רק** לקופסה שהבקר הקצה מראש
  (נתיב אקראי של 128 ביט), והבקר קורא כמנהל. האנדרואידים לא מחזיקים את מפתח ה-service account.
- **המכשירים שלך בלבד.** SMS Bridge מיועד להעברת הודעות בין מכשירים שבבעלותך. אין להשתמש בו כדי לקרוא הודעות של אדם אחר.
- **הסכמה ושקיפות.** בטלפון השולח יש מסך גילוי והסכמה לפני בקשת ההרשאה, אפליקציה גלויה שמסבירה מה היא עושה,
  הודעה קבועה "משתף SMS עם …", והתראה על כל משיכה. יש מתג השהיה וכפתור ניתוק.
- **ניתוק.** בבקר: "הסר" על טלפון מוחק את הקופסה שלו ומנתק אותו מיד. בשולח: "נתק את הטלפון הזה".
- האפליקציה **משנה את כללי מסד הנתונים** של הפרויקט, לכן כדאי פרויקט Firebase ייעודי.

## מבנה הקוד

```
sms-bridge/
  android/app/src/main/java/com/itamar/smsbridge/   (השולח — APK גנרי, בלי סודות)
    App.kt              מאתחל Firebase מההגדרות שבקישור החיבור
    PushService.kt      מקבל דחיפה, קורא, מצפין ומעלה. הקוד היחיד שרץ בלי שהאפליקציה פתוחה
    Enrollment.kt       פענוח קישור החיבור, רישום לדחיפות, פרסום רשומת החיבור המוצפנת
    PullPayload.kt      פענוח הבקשה ובניית התשובה (מכוסה בטסטים)
    Crypto.kt           AES-256-GCM (מכוסה בטסטים)
    Net.kt              כתיבה לא-מאומתת לקופסה של הטלפון במסד
    SmsRepository.kt    קריאה מתיבת ה-SMS ופתרון שמות אנשי קשר
    MainActivity.kt     מסך החיבור, ההסכמה, ההשהיה והניתוק
  web/index.html        הבקר (כל מכשיר עם דפדפן): הגדרה חד-פעמית, ניהול טלפונים, משיכה וצפייה — וגם מסך החיבור לשולח
```

כל הקוד של הבקר הוא קובץ אחד, בלי תלויות חיצוניות, ומדבר ישירות עם Google.

### גרסת Google Play

- `targetSdk`/`compileSdk` 36, `versionCode` 11 / `versionName` 4.0.1 (גרסאות 1-3 היו ה-APK שהופץ ידנית).
- ההרשאה הרגישה היחידה היא `READ_SMS` (חריג Play: "העברה/סנכרון SMS בין מכשירים" — של אותו משתמש). הרשאת אנשי הקשר ו-`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` הוסרו.
- לפני בקשת ההרשאה מוצג מסך גילוי והסכמה (`DisclosureActivity`) עם קישור למדיניות הפרטיות (`web/privacy.html`).
- אין שירות חזית (foreground service). העבודה נעשית ב-`FirebaseMessagingService` לכמה שניות לכל בקשה.
- חתימה: מפתח ההעלאה **מחוץ לריפו**. קובץ properties עם `storeFile`, `storePassword`, `keyAlias`, `keyPassword`:
  `./gradlew bundleRelease -PsmsbridgeSigning=/path/to/signing.properties` (או משתנה הסביבה `SMSBRIDGE_SIGNING`).
  בלעדיו, release נחתם במפתח debug (ל-CI).
