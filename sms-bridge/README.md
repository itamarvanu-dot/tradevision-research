# SMS Bridge — לראות את הודעות הסמסונג מהאייפון, בלחיצה

לוחצים **"רענן"** באייפון ← הסמסונג מתעורר לשנייה, שולח את ההודעות מהזמן האחרון ← הן מופיעות באייפון.
בשאר הזמן **האפליקציה בסמסונג לא רצה בכלל**.

- **אין צריכת סוללה.** אין שירות רקע, אין התראה קבועה, אין wake lock. הסמסונג מתעורר רק כשאתה לוחץ.
- **עובד מכל מקום**, כל עוד הסמסונג דולק ומחובר לאינטרנט (Wi‑Fi או סלולר). לא צריך שהטלפונים יהיו באותה רשת.
- **בלי Tailscale ובלי חשבון כפול.** לא מתחברים לשום חשבון באף אחד מהטלפונים.
- **אין מה להתקין באייפון.** רק אייקון במסך הבית.
- **מוצפן מקצה לקצה.** ההודעות מוצפנות בסמסונג (AES‑256‑GCM), ורק האייפון מחזיק את המפתח.
- **קריאה בלבד.** האפליקציה לא שולחת, לא מוחקת ולא משנה שום הודעה.

---

## איך זה עובד

```
  אייפון                         Google (Firebase, חינם)                 סמסונג
  ──────                         ───────────────────────                 ──────
  לחיצה על "רענן"  ──(1) דחיפה בעדיפות גבוהה──────────────────────▶  האפליקציה מתעוררת
                                                                       (2) קוראת SMS מהזמן שבחרת
                                  ◀──(3) מעלה אותן מוצפנות─────────────  וחוזרת לישון
  (4) מושך, מפענח, מציג  ◀────────  מסד נתונים
```

1. האייפון שולח דחיפה (FCM) בעדיפות גבוהה. זה אותו מנגנון שוואטסאפ משתמשת בו כדי להעיר טלפון ישן,
   והוא עובד גם כשהמסך כבוי והטלפון במצב חיסכון (Doze).
2. Google Play services מעירים את האפליקציה לכמה שניות. היא קוראת את ההודעות מהטווח שבחרת באייפון
   (15 דקות, שעה, 6 שעות, יום, 3 ימים, או 50 האחרונות).
3. היא מצפינה אותן ומעלה ל‑Firebase Realtime Database, ואז התהליך נגמר.
4. האייפון מושך את התשובה ומפענח אותה. בדרך כלל כל זה לוקח 2–5 שניות.

**בלי שרת משלנו.** Firebase הוא רק תיבת דואר מוצפנת. הוא חינמי בשימוש הזה (תוכנית Spark), בלי כרטיס אשראי.

## התקנה (פעם אחת, כ‑10 דקות)

### 1. פרויקט Firebase

אפשר לעשות את זה מהדפדפן בסמסונג עצמו. כך הקובץ כבר יהיה עליו.

1. נכנסים ל‑<https://console.firebase.google.com> עם חשבון Google רגיל ← **Create a project**.
   נותנים שם כלשהו, למשל `sms-bridge`. את Google Analytics אפשר לכבות.
2. ⚙️ **Project settings** ← לשונית **Service accounts** ← **Generate new private key** ← **Generate key**.
   יורד קובץ JSON. **זה המפתח לפרויקט, ולא שולחים אותו לאף אחד.**

וזהו. את שאר ההגדרות האפליקציה עושה לבד: רושמת את עצמה בפרויקט, יוצרת את מסד הנתונים ונועלת אותו,
ומעלה את דף האייפון לכתובת של הפרויקט שלך (`https://<שם-הפרויקט>.web.app`).

> אם האפליקציה מודיעה שלא הצליחה לרשום את עצמה: בקונסול **Add app** ← Android ← חבילה
> `com.itamar.smsbridge` ← **Register** ← מורידים `google-services.json`, ובוחרים באפליקציה את שני הקבצים יחד.
> אם היא לא הצליחה ליצור מסד נתונים: **Build ← Realtime Database ← Create database** (Locked mode),
> ואז **"השלם הגדרה"** באפליקציה.
>
> אם מופיעה הודעה שדף האייפון לא הועלה ל‑Firebase Hosting: בקונסול **Build ← Hosting ← Get started**
> (מספיק ללחוץ "Next" עד הסוף), ואז **"השלם הגדרה"**. חלופה: בהגדרות הריפו ב‑GitHub
> **Settings ← Pages ← Deploy from a branch** ← הענף של האפליקציה, תיקייה `/ (root)`. אז הקוד יפנה ל‑
> `https://itamarvanu-dot.github.io/tradevision-research/sms-bridge/web/`.

### 2. להתקין את האפליקציה בסמסונג

1. מורידים את ה‑APK: בריפו ← לשונית **Actions** ← הריצה האחרונה של **SMS Bridge APK** ← תחת **Artifacts** ← `sms-bridge-apk`.
   פורקים את ה‑ZIP ומקבלים `app-release.apk`.
2. פותחים אותו בסמסונג ומאשרים **התקנה ממקורות לא ידועים**.
   אם הגרסה הקודמת מותקנת, אפשר להתקין מעליה.
3. ב‑SMS Bridge:
   - **אשר הרשאות**: SMS (חובה), אנשי קשר (בשביל שמות) והתראות.
   - **בחר קובץ מפתח**: בוחרים את קובץ ה‑JSON מסעיף 1.
   - מחכים לסיום ההגדרה (כמה שניות) ולוחצים **"שלח לעצמי בקשת משיכה"**. אמור להופיע ✓.

### 3. לחבר את האייפון

1. בסמסונג מופיע קוד QR. סורקים אותו במצלמת האייפון ופותחים בספארי.
2. ההודעות נטענות מיד.
3. בספארי: **שיתוף ← הוסף למסך הבית**. מכאן זה אייקון שנפתח כמו אפליקציה. אין צורך לסרוק שוב.

### 4. שיענה תמיד (חשוב)

האפליקציה לא רצה ברקע, ולכן ההגדרות האלה **לא עולות בסוללה**. הן רק מונעות מסמסונג "להרדים"
אפליקציה שלא פותחים הרבה זמן. אם היא נרדמת, הדחיפה לא מגיעה:

- **הגדרות ← סוללה ← הגבלות שימוש ברקע ← אפליקציות שאף פעם לא נרדמות** ← להוסיף את SMS Bridge.
- בפרטי האפליקציה (כפתור **"פתח את הגדרות האפליקציה"**): לכבות **"השהה פעילות אם לא בשימוש"**.
- **לא** לבצע "עצירה בכוח" לאפליקציה. אנדרואיד חוסם דחיפות לאפליקציה שנעצרה בכוח, עד שפותחים אותה שוב.

## שימוש יומיומי

פותחים את האייקון באייפון. הוא מושך לבד. אם הוא כבר היה פתוח, לוחצים **"רענן הודעות"**.

- **טווח זמן**: הכפתורים מתחת לרענון. הבחירה נשמרת.
- **חיפוש** בגוף ההודעה ובשם השולח, וסינון **"לא נקראו"**.
- **קודי אימות**: בהודעות קוד, הספרות מוצגות ככפתור, ולחיצה מעתיקה אותן.
- הודעות שכבר נמשכו נשמרות באייפון, כך שגם כשהסמסונג לא זמין רואים את מה שהגיע קודם.
- בתחתית מוצגים דגם הסמסונג ומצב הסוללה שלו.

בסמסונג תופיע לכמה דקות התראה שקטה "נשלחו N הודעות לאייפון". כך תדע אם מישהו משך הודעות.

## אבטחה

- **הצפנה מקצה לקצה**: מפתח AES‑256 נוצר בסמסונג ועובר לאייפון רק בתוך קוד ה‑QR, בחלק שאחרי ה‑`#`
  (הדפדפן לא שולח את החלק הזה לשום שרת). ב‑Firebase נשמר רק מידע מוצפן.
- **מסד הנתונים נעול**: רק מפתח ה‑service account יכול לקרוא ולכתוב. היוצא מן הכלל היחיד הוא רשומת ההגדרה
  המוצפנת שהאייפון קורא פעם אחת, והיא נמצאת בנתיב אקראי של 128 ביט.
- **מפתח הפרויקט** נשמר באפליקציה בסמסונג ומועבר לאייפון רק מוצפן. מי שמחזיק אותו יכול לשלוח דחיפות
  לסמסונג ולקרוא מהמסד המוצפן, אבל בלי מפתח ה‑AES הוא לא יכול לפענח הודעות.
- **ניתוק**: **"נתק את האייפון (מפתח חדש)"** בסמסונג מבטל מיד את הקישור הקודם. כדי לבטל לגמרי את
  המפתח לפרויקט: בקונסול Firebase ← Service accounts ← מוחקים את המפתח, ובוחרים מפתח חדש באפליקציה.
- **השהיה**: המתג **"לאפשר לאייפון למשוך הודעות"** בסמסונג. כשהוא כבוי, האייפון מקבל "מושהה".
- האפליקציה **מחליפה את כללי מסד הנתונים** של הפרויקט, לכן כדאי להשתמש בפרויקט Firebase שמיועד רק לזה.

## מבנה הקוד

```
sms-bridge/
  android/app/src/main/java/com/itamar/smsbridge/
    App.kt              מאתחל את Firebase מההגדרות שנשמרו (בלי google-services.json בתוך ה-APK)
    PushService.kt      מקבל את הדחיפה, קורא, מצפין ומעלה. הקוד היחיד שרץ בלי שהאפליקציה פתוחה
    PullPayload.kt      פענוח הבקשה ובניית התשובה (מכוסה בטסטים)
    Pairing.kt          ההגדרה האוטומטית, רשומת החיבור המוצפנת, ניתוק, בדיקה עצמית
    Google.kt           קריאות REST ל-Google: OAuth, Realtime Database, FCM, רישום אפליקציה
    ServiceAccount.kt   חתימת JWT עם מפתח הפרויקט (מכוסה בטסטים)
    FirebaseConfig.kt   קריאת google-services.json (מכוסה בטסטים)
    Crypto.kt           AES-256-GCM (מכוסה בטסטים)
    SmsRepository.kt    קריאה מתיבת ה-SMS ופתרון שמות אנשי קשר
    MainActivity.kt     מסך ההגדרה, קוד ה-QR והסטטוס
  web/index.html        כל הממשק של האייפון: קובץ אחד, בלי תלויות חיצוניות
```

דף האייפון נארז בתוך ה‑APK, וההגדרה מעלה אותו ל‑Firebase Hosting של הפרויקט. גרסה חדשה של האפליקציה
מעלה גרסה חדשה של הדף בפתיחה הבאה. אם ההעלאה נכשלת, הקוד מפנה לכתובת ברירת המחדל
(`-Psmsbridge.pageUrl=…` בזמן הבנייה), ואפשר לשנות אותה גם מתוך האפליקציה. הדף סטטי ואין בו סודות.
