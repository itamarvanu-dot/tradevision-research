# SMS Bridge — הודעות ה-SMS של כמה טלפוני אנדרואיד, על האייפון, בלחיצה

לוחצים **"רענן"** באייפון ← כל טלפון אנדרואיד שחיברת מתעורר לשנייה, שולח את ההודעות מהזמן האחרון ← הן מופיעות אצלך.
בשאר הזמן **האפליקציה באנדרואיד לא רצה בכלל**.

- **שני תפקידים.** אתה (ה**בקר**) מגדיר פעם אחת Firebase — על האייפון בלבד. כל אנדרואיד שתחבר הוא **שולח**:
  הוא רק מתקין אפליקציה ופותח קישור. **אין לו גישה ל-Firebase, אין חשבון, אין הגדרות.**
- **כמה טלפונים לאייפון אחד.** מחברים 2, 3 או יותר. ההודעות מוצגות יחד עם תווית לכל טלפון, או מסוננות לפי טלפון.
- **בלי Tailscale ובלי צריכת סוללה.** אין שירות רקע באנדרואיד; הוא מתעורר רק כשאתה מבקש.
- **מוצפן מקצה לקצה.** לכל טלפון מפתח AES משלו, שעובר רק בקישור החיבור. Firebase רואה רק טקסט מוצפן,
  והאנדרואידים לא מחזיקים שום מפתח ניהול.
- **קריאה בלבד ובהסכמה.** האפליקציה לא שולחת/מוחקת הודעות. בטלפון השולח יש אייקון גלוי, הודעה קבועה
  "משתף SMS עם …", והתראה על כל משיכה. **התקן רק בטלפון שבעליו מסכים לשיתוף.**

---

## איך זה עובד

```
  האייפון (בקר)                       Google (Firebase, חינם)                  אנדרואיד (שולח)
  ─────────────                       ───────────────────────                  ───────────────
  "רענן את כל הטלפונים"  ──דחיפה בעדיפות גבוהה לכל טלפון──────────────────▶  מתעורר לכמה שניות
                                                                              קורא SMS מהטווח שבחרת
                              ◀──מעלה מוצפן לקופסה שלו─────────────────────  וחוזר לישון
  מושך, מפענח ומציג  ◀───────  מסד נתונים (קופסה לכל טלפון)
```

- כל טלפון = "קופסה" (נתיב סודי במסד הנתונים) עם מפתח הצפנה משלה.
- הבקר (האייפון) מחזיק את מפתח ה-service account, שולח את הדחיפות וקורא את התשובות כמנהל.
- השולח (האנדרואיד) מחזיק רק את ההגדרות הציבוריות + הקופסה + המפתח שקיבל בקישור. הוא כותב את תשובתו
  ישירות למסד (כתיבה לא-מאומתת לנתיב סודי שהבקר הקצה מראש), בלי שום מפתח מנהל.

**בלי שרת משלנו.** Firebase הוא רק תיבת דואר מוצפנת, חינמי לשימוש הזה (תוכנית Spark), בלי כרטיס אשראי.

## התקנה

### א. פעם אחת, על האייפון (הבקר) — כ-5 דקות

1. פרויקט Firebase חינמי: <https://console.firebase.google.com> ← **Create a project**.
2. רושמים אפליקציית אנדרואיד: **Add app ← Android**, שם החבילה **`com.itamar.smsbridge`** ← **Register app** ←
   מורידים **`google-services.json`**.
3. מפתח ניהול: ⚙️ **Project settings ← Service accounts ← Generate new private key** ← יורד קובץ JSON.
4. פותחים את **דף הבקר** באייפון (ראו "איפה הדף" למטה), בוחרים את **שני הקבצים** שירדו, ולוחצים "התחל הגדרה".
   הדף יוצר ונועל את מסד הנתונים לבד. הכל נשמר רק על האייפון שלך.

> אם אין Realtime Database בפרויקט, הדף יוצר אותו. אם תעדיף ליצור ידנית: **Build ← Realtime Database ← Create database**.

### ב. לכל טלפון אנדרואיד שתרצה לחבר

1. בדף הבקר: **"+ חבר טלפון חדש"**, נותנים שם (למשל "אמא"). נוצר **קישור חיבור** — שולחים אותו לבעל הטלפון.
2. בעל הטלפון: מתקין את **SMS Bridge** (קובץ ה-APK; ראו "השגת ה-APK"), פותח את הקישור ← **"פתח באפליקציה"**,
   ונותן הרשאת **SMS**. זהו — אין לו שום הגדרה נוספת.
3. שיעבוד תמיד: בטלפון השולח, **הגדרות ← סוללה ← אפליקציות שאף פעם לא נרדמות** ← להוסיף את SMS Bridge,
   ובפרטי האפליקציה לכבות "השהה פעילות אם לא בשימוש". זה לא עולה בסוללה (אין רקע), רק מונע הרדמה.

חוזרים על ב' לכל טלפון נוסף.

### השגת ה-APK

ה-APK **גנרי וללא סודות** (הוא מוגדר כולו מקישור החיבור), אז אפשר פשוט לשלוח את הקובץ בצ'אט. להורדה:
לשונית **Actions** בריפו ← הריצה האחרונה של **SMS Bridge APK** ← תחת **Artifacts** ← `sms-bridge-apk`.
לבנייה מקומית: `cd sms-bridge/android && ./gradlew assembleRelease`.

### איפה הדף (הבקר)

דף הבקר הוא קובץ סטטי יחיד, `sms-bridge/web/index.html`, בלי סודות. אפשר לארח אותו בכל מקום עם HTTPS.
הכי פשוט: בהגדרות הריפו ב-GitHub **Settings ← Pages ← Deploy from a branch** ← הענף, תיקייה `/ (root)`,
ואז הדף ב-`https://itamarvanu-dot.github.io/tradevision-research/sms-bridge/web/`. קישורי החיבור שהדף מייצר
מצביעים חזרה לאותה כתובת, כך שגם מסך החיבור של השולח מוגש מאותו דף.

## שימוש יומיומי

פותחים את דף הבקר באייפון (נוח להוסיף למסך הבית: שיתוף ← הוסף למסך הבית).

- **"רענן את כל הטלפונים"** מושך מכולם במקביל. אפשר גם לרענן טלפון בודד מכרטיס הטלפון.
- **טווח זמן** (15 דק׳ עד 3 ימים, או 50 אחרונות) ו**בחירת טלפון** (הכל / טלפון מסוים) בשורות הכפתורים.
- **חיפוש** בגוף ההודעה, בשם השולח ובשם הטלפון; סינון **"לא נקראו"**.
- **קודי אימות** מוצגים ככפתור העתקה. הודעות חדשות מודגשות בירוק.
- לכל טלפון מוצגים הדגם, מצב הסוללה ומתי עודכן לאחרונה. הודעות שנמשכו נשמרות על האייפון.
- **החשבון נשמר בענן.** רשימת הטלפונים שחיברת נשמרת גם במסד הנתונים (באזור שרק המנהל ניגש אליו).
  אם הדפדפן נמחק, או שאתה פותח את הדף ממכשיר אחר — פשוט בחר שוב את שני הקבצים, וכל הטלפונים חוזרים.
  זה אותו חשבון תמיד; שני הקבצים הם הזהות שלך.

## אבטחה ופרטיות

- **הצפנה מקצה לקצה לכל טלפון.** מפתח AES-256 נפרד לכל טלפון, שעובר רק בקישור החיבור (בחלק שאחרי ה-`#`,
  שהדפדפן לא שולח לשרת). ב-Firebase נשמר רק טקסט מוצפן.
- **מסד נתונים נעול.** קריאה וכתיבה כלליות אסורות. אנדרואיד יכול לכתוב **רק** לקופסה שהבקר הקצה מראש
  (נתיב אקראי של 128 ביט), והבקר קורא כמנהל. האנדרואידים לא מחזיקים את מפתח ה-service account.
- **הסכמה ושקיפות.** בטלפון השולח יש אפליקציה גלויה שמסבירה מה היא עושה, הודעה קבועה "משתף SMS עם …",
  והתראה על כל משיכה. יש מתג השהיה וכפתור ניתוק. **אין להתקין על טלפון בלי ידיעת והסכמת בעליו.**
- **ניתוק.** בבקר: "הסר" על טלפון מוחק את הקופסה שלו ומנתק אותו מיד. בשולח: "נתק את הטלפון הזה".
- האפליקציה **משנה את כללי מסד הנתונים** של הפרויקט, לכן כדאי פרויקט Firebase ייעודי.

## מבנה הקוד

```
sms-bridge/
  android/app/src/main/java/com/itamar/smsbridge/   (השולח — APK גנרי, בלי סודות)
    App.kt              מאתחל Firebase מההגדרות שבקישור החיבור
    PushService.kt      מקבל דחיפה, קורא, מצפין ומעלה. הקוד היחיד שרץ בלי שהאפליקציה פתוחה
    Enrollment.kt       פענוח קישור החיבור, רישום לדחיפות, פרסום רשומת החיבור המוצפנת
    PullPayload.kt      פענוח הבקשה ובניית התשובה (מכוסה בטסטים)
    Crypto.kt           AES-256-GCM (מכוסה בטסטים)
    Net.kt              כתיבה לא-מאומתת לקופסה של הטלפון במסד
    SmsRepository.kt    קריאה מתיבת ה-SMS ופתרון שמות אנשי קשר
    MainActivity.kt     מסך החיבור, ההסכמה, ההשהיה והניתוק
  web/index.html        הבקר (האייפון): הגדרה חד-פעמית, ניהול טלפונים, משיכה וצפייה — וגם מסך החיבור לשולח
```

כל הקוד של הבקר הוא קובץ אחד, בלי תלויות חיצוניות, ומדבר ישירות עם Google.
